# Jira/Confluence Automation

A prototype toolkit for exploring Jira and Confluence automation workflows, built with AI assistance.

## Project Areas

- `jira-weekly-status/` contains a React frontend and Node.js backend scaffold for generating Jira weekly status reports. The application files are placeholders; Dockerfiles and implementation are still needed before the Compose services can run.
- `project-jira-automation/` contains a Python-based Jira automation project with `scripts/` and `data/` directories.

## Status

This repository is an early-stage prototype. See the README and project documentation within each project directory for local details.
